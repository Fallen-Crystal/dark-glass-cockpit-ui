# Examples

- `full-dashboard.html` — 全能力通用 Demo。
- `fluid-cards.html` — 聚焦四张 Fluid Glass 指标卡。
- `acrylic-carousel.html` — 聚焦 3D 亚克力堆栈/环形卡片。
- `breathing-dashboard.html` — 关闭粒子启动层，直接观察全局统一呼吸。
- `particle-sphere.html` — 聚焦 Particle Core 启动环境。

这些聚焦示例为了保持参考实现完整，仍保留全量 DOM/runtime 依赖，只通过展示层突出单一模块；生产项目应按 `SKILL.md` 选择性拆入组件。
