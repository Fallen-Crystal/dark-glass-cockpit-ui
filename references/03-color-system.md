# Color System

## Neutral baseline

- Background: `#000000`
- Deep surface: `#080D0B`
- Surface: `#101713`
- Raised surface: `#161D1A`
- Text primary: `#F2F5F3`
- Text secondary: `#C2CBC6`
- Text tertiary: `#9EA9A3`

## Default accent triplet

- Accent: `#00E676`
- Highlight: `#93FFD0`
- Shadow accent: `#006B3A`

## Preset families

- green
- cyan
- blue
- purple
- silver

Use semantic triplets (accent/highlight/shadow) rather than a single color so acrylic highlights and shadows remain coherent.
