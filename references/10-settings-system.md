# Settings System

## Principles

- live preview
- non-modal visual tuning
- centralized parameters
- safe input clamping
- local persistence
- reset to defaults
- no user-specific storage keys

## Suggested keys

- `dark-glass-cockpit-ui-state-v1`
- `immersive-fluid-glass-v1`
- `immersive-theme-material-v1`
- `immersive-breathing-v1`
- `immersive-particle-core-v1`

When embedding in another product, prefix these keys with the host app namespace.
