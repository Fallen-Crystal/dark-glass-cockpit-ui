# Acrylic 3D Cards

## Card material layers

- acrylic shell
- left/right side refraction strips
- top edge
- frosted core
- inner paper/details
- outer rim
- focused accent material

## Stack mode

Primary parameters:

- perspective
- spread
- depth
- tilt
- active lift
- global size
- card width/height
- active scale
- blur
- glow
- acrylic alpha
- frost strength
- rim strength

## Orbit mode

Primary parameters:

- orbit X/Z radius
- vertical ripple
- lean
- rear scale
- inertia
- selection duration
- snap duration
- highlight duration
- easing
- auto-center
- cruise speed

Map collection data through an adapter; never hard-code domain-specific item names in the component implementation.
