# Layout System

Desktop cockpit default:

- Sidebar: 200–240px
- Main: minmax(0, 1fr)
- Detail: 280–340px
- Outer padding: 18–28px
- Gap: 12–18px

Main workspace can contain:

1. topbar
2. 3–4 KPI/fluid cards
3. two-column board: compact activity + primary visual/data surface
4. timeline or secondary data region

Do not force the three-column shell on mobile. Collapse secondary panels or provide an alternate mobile layout.
