# Theme & Material System

Themes are semantic token sets rather than full style rewrites.

Each theme provides:

- background
- panel RGB
- panel-deep RGB
- accent
- highlight
- shadow accent

Material controller provides:

- master enable
- natural vs uniform hierarchy
- panel opacity
- surface haze
- background blur
- material brightness compensation
- edge highlight
- hierarchy contrast
- region scopes
- region offsets
- optional fluid color/surface synchronization

Live settings drawers should not dim the whole application unless modal behavior is explicitly required.
